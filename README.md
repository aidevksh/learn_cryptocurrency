# 장부와 금고

처음 배우는 사람을 위한 **암호화폐 원리와 거래소 보안 인터랙티브 교과서**입니다. 파일 하나(`index.html`)로 되어 있어 브라우저에서 바로 열립니다.

> 비트코인은 누가 얼마를 가졌는지 적힌 **장부**이고, 거래소는 그 장부 속 코인을 움직이는 열쇠를 고객 대신 보관하는 **금고**입니다.

## 구성

| 파트 | 다루는 내용 |
|---|---|
| 1. 장부 | 해시, 블록과 체인, 머클 트리, 작업증명·지분증명, 개인키·서명·니모닉, 거래와 발행량 |
| 2. 금고 | 거래소 내부 원장, 핫·웜·콜드월렛, 멀티시그·MPC·HSM, 출금 관문, 준비금 증명, 한국의 규제 |
| 3. 사고 기록 | 2014–2026년 거래소·지갑 사고 17건 (익명 처리) |
| 4. 내 지갑 지키기 | 보안 점검표, 퀴즈 10문항, 용어 사전 |

## 실습 12개

해시 계산기 · 블록체인 변조와 채굴 · 머클 트리 포함 증명 · 공격 성공 확률(사토시 백서 11절) · 지갑 생성과 서명(secp256k1) · 니모닉 해부(BIP-39) · 서명 난수 재사용 공격 · 거래소 장부와 블록체인 대사 · 콜드월렛 비율 시뮬레이터 · 멀티시그·MPC 승인 · 출금 관문 · 준비금 증명 검증

SHA-256, RIPEMD-160, secp256k1 ECDSA, Base58Check, Bech32는 외부 라이브러리 없이 페이지 안에서 직접 계산하며, 어떤 데이터도 외부로 보내지 않습니다.

## 보는 법

`index.html`을 내려받아 브라우저로 엽니다. 인터넷에 연결돼 있으면 Google Fonts 글꼴을 불러오고, 오프라인이면 시스템 글꼴로 표시됩니다.

## 알아 둘 점

- 자료 기준일은 2026년 11월 3일입니다. 최근 사고의 수치는 조사에 따라 바뀔 수 있습니다.
- 사고 사례는 특정 기업이나 기관을 지목하지 않도록 이름을 알파벳(거래소 A~Q 등)으로 바꾸고 금액과 수량을 반올림했습니다.
- 학습용 자료이며 투자 권유가 아닙니다. 실습에서 만든 개인키로 실제 자산을 받지 마세요.
